# Soluna 游戏引擎文档

Soluna 是一个使用 Lua 编写 2D 游戏的框架，支持多线程。

## 概述

Soluna 是一个轻量级、高性能的 2D 游戏引擎，它利用 Lua 进行脚本编写，并通过 ltask 提供内置的多线程功能。它设计简单而强大，非常适合开发跨平台 2D 游戏。

## 特性

- **Lua 脚本**: 使用 Lua（一种轻量级和快速的脚本语言）编写游戏逻辑
- **多线程**: 通过 ltask 内置支持并发操作
- **跨平台**: 支持 Windows、macOS、Linux 和 WebAssembly (WASM)
- **现代渲染**: 使用 Sokol 进行高效图形渲染
- **灵活布局**: 基于 Yoga 的 UI 元素布局系统
- **精灵管理**: 高效的精灵批处理和纹理图集支持
- **文本渲染**: 支持 TrueType 字体的高级文本渲染
- **手柄支持**: 内置游戏手柄输入处理
- **资源管理**: 高效加载和管理游戏资产

## 核心组件

### 渲染系统
- 使用 Sokol 的硬件加速 2D 渲染
- 材质系统，支持默认、文本、四边形和遮罩材质
- 精灵批处理以优化性能
- 多个渲染通道和视口

### 布局引擎
- 使用 Facebook 的 Yoga 库实现类似 Flexbox 的布局
- 响应式 UI 设计能力
- 动态元素定位和大小调整
- 支持嵌套布局

### 资产管理
- 图像加载和处理
- 用于高效纹理打包的精灵包系统
- 支持 TrueType 的字体管理
- 使用 datalist 格式的数据序列化

### 多线程
- 使用 ltask 的面向服务架构
- 服务间的消息传递
- 定时器服务用于计划任务
- 异步资源加载

## 架构

Soluna 遵循基于服务的架构，不同的子系统作为独立服务通过 ltask 通信：

- **渲染服务**: 处理所有渲染操作
- **加载器服务**: 管理资产加载和缓存
- **定时器服务**: 提供计时和调度功能
- **手柄服务**: 处理游戏手柄输入
- **设置服务**: 管理游戏配置
